## Sobre mim

Trabalho principalmente em aplicações para **mobile, streaming e web**, com foco em interface, desempenho, estabilidade e experiência de uso.

Hoje meu principal projeto é o **XTOYBOX**. Também desenvolvo versões e ferramentas relacionadas para TV, iOS, web e automação.

Gosto de trabalhar de forma prática: testar, corrigir o que incomoda no uso real e evoluir o projeto sem adicionar complexidade desnecessária.
